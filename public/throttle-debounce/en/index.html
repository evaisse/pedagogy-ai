Decision guide

  • Debounce Waits for a quiet period, then emits the latest event.
  • Throttle Limits output frequency while events keep arriving.

Practical choices

Search input
Debounce so requests wait until typing settles.
Resize events
Debounce layout work after the window stops changing.
Scroll events
Throttle progress updates to a steady cadence.
Pointer movement
Throttle drawing or hit testing during continuous motion.

Compact JavaScript

Debounce

function debounce(fn, delay) {
  let timerId;
  return (...args) => {
    clearTimeout(timerId);
    timerId = setTimeout(() => fn(...args), delay);
  };
}

Throttle

function throttle(fn, interval) {
  let lastRun = 0;
  return (...args) => {
    const now = performance.now();
    if (now - lastRun >= interval) {
      lastRun = now;
      fn(...args);
    }
  };
}
