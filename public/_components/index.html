Component contract

API

Surface Name Purpose
Attribute kicker Short uppercase label above the component title.
Attribute title Main heading rendered inside the component.
Attribute summary Compact explanatory text under the heading.
Element <concept-callout> Renders a compact explanation callout with a default slot for inline examples.
Attribute variant Callout tone: example, metaphor, note, or story.
Attribute marker Optional short marker rendered in the left badge.
Attribute step, total Optional story index rendered in the marker as X/Y.
Attribute theme Visual identity for recurring story threads, such as theater or field.
Property data.tokens Array of token objects with label, state, and meta.
Event token-flow-select Fires when a token is selected. Payload is available in event.detail.
Element <source-list> Renders child links or assigned sources data as a scoped source list.
Attribute kicker, title, summary Header copy for the source list.
Attribute density="compact" Renders source items as a compact inline bullet list instead of cards.
Property sources Array of source objects with href, label, description, and meta.
Element <openai-endpoint-settings> Validates the local OpenAI chat completions proxy and stores endpoint/model settings locally.
Method getSettings() Returns the stored endpoint settings for client-side API calls.
Event openai-endpoint-settings-change Fires when endpoint configuration is saved or cleared.
