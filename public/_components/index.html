token-flow

A compact prompt-token visualization for cache hits, cache writes, fresh suffixes, and cache misses.

Default render <token-flow>
Configured data .data = {...}
Interactive states token-flow-select
Selected token None

Click a token to inspect the event payload.

Component contract

API

Surface Name Purpose
Attribute kicker Short uppercase label above the component title.
Attribute title Main heading rendered inside the component.
Attribute summary Compact explanatory text under the heading.
Property data.tokens Array of token objects with label, state, and meta.
Event token-flow-select Fires when a token is selected. Payload is available in event.detail.
